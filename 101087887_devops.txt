COMP3104 DevOps

DevOps connects software development and operations through collaboration and automation.
In this course, we practise using Git and GitHub to track changes and work together.
This assignment applies these ideas through individual branches, commits, pull requests, and continuous integration.

Version Control and Collaboration

Git records changes in commits, allowing developers to review the history of a project.
Each member uses a separate branch to work on their contribution.
A pull request allows teammates to review changes before they are merged into main.
Merge conflicts happen when Git cannot automatically combine changes, so the team must review and resolve them.
