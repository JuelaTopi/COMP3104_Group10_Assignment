Introduction to DevOps

DevOps is an approach that brings software development and IT operations together to improve collaboration and efficiency. The COMP3104 DevOps course introduces students to tools and practices used in modern software development, including Git, GitHub, version control, continuous integration, and automation. These skills help teams develop, test, and deliver software more reliably.

Git, Commits, and Branches

Git is a version control system that helps developers track changes in their code and manage different versions of a project. A commit records a specific set of changes, making it easier to review project history or restore previous versions. Branches allow developers to work on new features or improvements independently without affecting the main project. GitHub provides an online platform where teams can store repositories and collaborate using Git.

Pull Requests and Collaboration

Pull requests are an important feature of GitHub that allow developers to propose changes before merging them into the main branch. Team members can review the changes, provide feedback, and suggest improvements. This process helps maintain code quality and reduces errors. Collaboration through pull requests also improves communication and allows multiple developers to contribute to the same project while keeping their work organized.

Continuous Integration and GitHub Actions

Continuous Integration (CI) is a DevOps practice where developers regularly combine their code changes into a shared repository. Automated workflows can check the code for errors and help identify problems early. GitHub Actions is a tool that allows developers to automate tasks such as building, testing, and validating projects. These workflows can run automatically when code is pushed or when a pull request is created. CI helps improve software quality and makes collaboration more efficient.
